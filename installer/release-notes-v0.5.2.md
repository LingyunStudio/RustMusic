# RustMusic v0.5.2

## 新功能：列表自动定位 + 「回到当前歌曲」

- **打开即定位**：打开播放队列、歌单（自建/导入）、在线歌单/榜单、B 站空间列表、Navidrome 全部歌曲时，自动滚动到正在播放的那首歌并居中——不再每次都停在第一行
- **「回到当前歌曲」药丸**：正在播放的行滚出视野时，列表底部浮出药丸按钮，点击平滑滚回；行回到视野内自动消失。定位从"强制传送"变成"可撤销的捷径"
- **资料库/艺人专辑页保持从顶部开始**（浏览语义不自动传送），由药丸承担定位职责
- **队列跟随播放**：队列面板开着时切歌，自动滚到新的当前行；手动滚动即暂停跟随，点药丸恢复
- 顺带修复：歌单里的本地曲目此前从不显示"正在播放"高亮

## 新功能：队列自动续页

搜索结果、在线榜单、B 站空间、Navidrome 全部歌曲按页加载的列表，播到本页最后一条时**自动加载下一页并追加进队列**——最后一首自然播完后无缝继续，不再需要手动点"加载更多"。歌单/每日推荐为整单加载，天然无需续页。

## 新功能：网易翻译歌词

外语歌播放时，当前行下方显示中文翻译小字（逐字染色不受影响）。翻译来自网易云官方翻译库，随逐字/行级歌词一并缓存。

## 新功能：在线歌词缓存

网易云 / QQ / 酷狗的歌词（含逐字时间轴与翻译）按曲目缓存到本地数据库，同一首歌第二次播放歌词瞬时呈现，不再重复网络请求。

## 优化

- **音量 / 定时播放弹窗背景加固**：浅色主题下背景不透明度从 7% 提到 97%，不再透底看不清
- **歌词来源标记**：播放页封面下方显示当前歌词来源（逐字 KRC / 逐字 YRC / 行级 LRC / 字幕），逐字歌词是否真实生效一目了然；逐字回落行级的原因落日志
- **编译警告清零 + 新增 GitHub Actions CI**（push/PR 自动运行前端构建与 Rust 单测）
