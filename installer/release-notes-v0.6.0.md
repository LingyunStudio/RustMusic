# RustMusic v0.6.0

## 新功能

- **Windows 任务栏歌词**：当前歌词行显示在任务栏时钟左侧，随托盘与显示器变化自动跟随；支持选择显示器（全部 / 主屏 / 副屏）与自定义颜色。DirectWrite 渲染，笔画与系统原生文字观感一致。
- **Linux 平台支持**：Linux 端与 Windows 功能对齐，提供 deb / AppImage 安装包。系统集成（MPRIS 媒体控制、托盘、凭据管理）、GNOME 顶栏菜单栏歌词（内置 Shell 扩展，设置页一键安装）、桌面歌词置顶与鼠标穿透（Wayland 自动走 XWayland）。
- **跨平台自动更新**：按当前平台自动匹配 Release 附件（Windows 安装包 / Linux AppImage），AppImage 下载校验后原子替换更新。
- **QQ 音乐微信扫码登录**：登录弹窗支持 QQ / 微信切换，与 QQ 扫码共用凭证存储，搜索、取链、逐字歌词、歌单导入直接生效。
- **音频律动**：新增音频律动引擎，播放页新增律动层与黑胶动态皮肤。

## 修复

- 榜单翻页定位修复；若干平台兼容与构建修复。
