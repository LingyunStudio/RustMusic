# RustMusic v0.6.0

## 新功能

- **Windows 任务栏歌词**：当前歌词行显示在任务栏时钟左侧，随托盘与显示器变化自动跟随；支持选择显示器（全部 / 主屏 / 副屏）与自定义颜色；DirectWrite 渲染，笔画与系统原生文字观感一致。
- **Linux 平台支持**：Linux 端与 Windows 功能对齐，提供 deb / AppImage 安装包——MPRIS 媒体控制、系统托盘、凭据管理、桌面歌词置顶与鼠标穿透（Wayland 自动走 XWayland），WASAPI 独占等平台差异项自动适配。
- **GNOME 顶栏菜单栏歌词**：内置 GNOME Shell 扩展（兼容 45-50），设置页一键安装；位置自动贴住托盘图标、间奏保留占位、颜色可自定义、超长省略号截断。
- **跨平台自动更新**：应用内检查 GitHub Release 并按当前平台匹配附件（Windows 安装包 / Linux AppImage，架构自动匹配），下载带 SHA-256 校验与进度，AppImage 原子替换后自动重启。
- **QQ 音乐微信扫码登录**：登录弹窗支持 QQ / 微信切换，与 QQ 扫码共用凭证存储，搜索、取链、逐字歌词、歌单导入直接生效。
- **音频律动引擎与律动层**：Rust 引擎侧完成 FFT 频谱分析（36 对数频段 + 节拍检测，30Hz 事件），播放页新增律动层（频谱柱、节拍涟漪、能量光晕，合成器路径零 React 重渲染），皮肤面板新增音频律动开关。
- **黑胶动态皮肤**：唱片旋转、频谱错拍起伏、声波扩散、音符漂浮、光晕呼吸五层动画；律动激活时背景自动切换为静态基座变体。
- **输出设备选择器组件化**：玻璃风 Portal 下拉选择器替换原生 select，两端渲染风格一致。

## 优化

- **前台低内存治理**：完善 WebView2 深度休眠（托盘挂起回收渲染内存，后台自动切歌完成后延迟重新休眠），前台以低内存目标级别运行，皮肤动效与律动层全走合成器路径。
- 封面取色网络失败自动重试一次；仓库统一 LF 行尾。

## 修复

- 榜单「加载更多」翻页后列表跳回顶部、正在播放行丢失的问题。
- 浅色主题下播放页歌词远行几乎不可见的问题。
- 若干平台兼容与构建修复（CI）。
