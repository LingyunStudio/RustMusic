# RustMusic v0.5.4

## 新功能

- **外部文件与文件夹拖拽导入**：支持直接将本地音频文件或文件夹拖入应用窗口。单曲拖入即刻解析入库并开始播放；文件夹拖入自动添加至媒体库监控目录并启动后台扫描；拖拽悬停时展示精致的视觉提示层。
- **播放列表批量管理与删除**：
  - 侧边栏「播放列表」支持一键进入批量管理模式，支持多选、全选并批量删除歌单，附带二次确认弹窗。
  - 歌单详情页新增「批量管理」工具栏，支持批量从歌单中移除歌曲（带确认弹窗，明确提示不影响本地源文件）。
- **资料库歌曲从硬盘永久删除**：资料库单曲右键菜单及批量操作栏支持「从硬盘删除」功能，带二次确认提示及文件完整路径显示，安全清理磁盘音频文件并自动同步更新播放列表、数据库记录与播放队列。
- **快进与快退控制**：底栏播放控制区新增快退（5秒）与快进（5秒）按钮；全局支持左右方向键（<kbd>←</kbd> / <kbd>→</kbd>）快捷键步进控制（长按平滑步进，自动过滤组合修饰键）。
- **托盘图标桌面歌词动态控制**：托盘右键菜单新增桌面歌词控制项，根据桌面歌词实际状态实时切换选项文本（开启桌面歌词 / 关闭桌面歌词 / 解锁桌面歌词），点击直接切换对应状态。
- **设置页面文件管理联动**：媒体库监控文件夹与下载保存目录新增「在文件管理器中打开/显示」按钮，方便直接定位本地文件。

## 修复与优化

- **曲目列表序号与播放按钮重叠修复**：修正当前播放曲目行在悬浮时序号与播放/暂停按钮重叠的视觉瑕疵，正在播放时清晰展现暂停按钮状态。
- **播放队列删除联动校准**：修复删除当前播放曲目或历史曲目时播放队列 `qIndex` 偏移导致切歌跳过曲目的问题。
- **歌单切换状态清理**：修复歌单详情页跨歌单切换时残留上一歌单批量勾选条目的问题。
- **缓存删除安全加固**：限定封面文件清理严格处于缓存目录内部，杜绝路径逃逸。
