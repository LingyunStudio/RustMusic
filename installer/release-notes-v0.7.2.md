# RustMusic v0.7.2

## v0.7.2 更新内容

- **三大界面设计体系架构深度重构与代码消冗**：
  - 深度重构主题架构，抽象出通用页面骨架组件（`ViewShell`）与主题感知系统，将分散在标准（Standard）、液态玻璃（Liquid Glass）、复古拟物（Skeuomorphic）三套主题文件中 90% 以上重复的 UI 框架与业务逻辑完全解耦统一，净减少 21,500+ 行冗余代码。
  - 严格保持各大主题独有的视觉工艺与交互细节：
    - **复古拟物**：精细保留金属拉丝冷轧面板、沉头金属螺栓、铝合金磨砂微浮雕旋钮、分贝推子、金属 Logo 铭牌、LCD 状态舱背光及多色状态 LED 指示灯。
    - **液态玻璃**：完整保留高斯模糊悬浮 Dock、液态呼吸发光胶囊、双列自适应面板与强调色派生玻璃光泽。
    - **标准现代**：保持经典毛玻璃通透质感与弹性流排版。
- **拟物主题布局重叠与呼吸间隙校准**：
  - 彻底修复网易云音乐、QQ 音乐、酷狗音乐等在线音源视图中，歌曲列表卡片与底部拟物硬件加高播放控制台贴合无间距、在特定分辨率下出现视觉重叠的问题。
  - 针对拟物主题定制底层防遮挡内边距（`pb-[96px]`），确保拟物机架卡片与底部金属控制台之间精确呈现 6px 的优雅呼吸间隙。
- **酷狗音乐音质匹配与取链重大修复**：
  - 修复歌单音频 ID 解析错误导致纯音乐播放与高阶音质无音源的问题：修正歌单通道误将内部 `audio_id` 当作 `album_audio_id` 的问题，改用 `mixsongid`/`add_mixsongid` 并正确解析 `relate_goods`。
  - 完善权益接口 `album_audio_id` 与 `album_id` 的提取与缓存机制，解决高阶音质（蝰蛇全景声/超清等）因缺失关联 ID 导致的取链失败。
  - 在 `v5/url` 取链中增加返回 hash 强校验，检测到服务端因错误 ID 混淆返回其它歌曲时自动清零 ID 无缝重试。
  - 优化母带音质匹配与权益查询以纯 hash 为准，避免带入错误 ID；消除「蝰蛇母带」与「蝰蛇超清」正常同级匹配时的误报降级提示。
- **音频引擎跨采样率与多声道重采样锁死修复**：
  - 修复在下混多声道全景声（如 6 声道 44.1kHz/48kHz）与超清/母带高解析度音频（96kHz/192kHz）之间连续切歌时，底层重采样器锁死在旧采样率导致播放音速异常或无声的问题。
  - 换曲瞬间为混音器（Mixer）独立重新连接 Player 实例，彻底物理隔离不同曲目与音质之间的采样率与声道上下文，确保高解析音频与多声道音频之间的无缝纯净切换。
