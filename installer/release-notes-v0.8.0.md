# RustMusic v0.8.0

## v0.8.0 更新内容

### 主题与界面全面升级
- **拟物主题（Skeuomorphic）深度重塑**：
  - 全新精密触感 Hi-Fi 视觉语言：暗色采用温润炭黑阳极氧化金属配色，浅色升级为 Braun / Dieter Rams 暖象牙陶瓷与香槟银铝风格，去除生硬竖条纹与高对比塑料斜面。
  - 重做黑胶直驱唱机播放页、立体 CNC 唱臂停靠支座与双通道动态模拟 VU 电平表；修复侧边栏与底部播放栏布局拥挤及重叠问题，降低列表行内按钮视觉噪音。
- **液态玻璃与标准主题细节打磨**：
  - 新增液态玻璃滤镜层，优化播放页歌词区径向遮罩边界，修复启动闪屏与三主题多处样式瑕疵。
- **专辑封面智能裁切**：自动识别并裁剪专辑封面单侧/双侧扫描白边，规范居中显示。

### 歌词与个性化设置增强
- **本地歌曲三源自动歌词匹配**：支持自动匹配、内部缓存、手动切换候选歌词与可选导出到本地。
- **自定义缓存目录与快捷键**：支持自定义缓存目录并自动迁移已有缓存；新增可自定义全局/应用内快捷键，精简设置说明。
- **歌词同步与托盘体验修复**：修复任务栏歌词重绘、歌词暂停高亮与时间偏移、本地后补 LRC/QRC 解析，以及系统托盘续播与防误挂起问题。

### 音频引擎与在线音源修复
- **音频引擎稳定性**：修复共享流缓存失效、在线切回不起播、WASAPI 独占模式拖动异常与频谱越界问题。
- **在线音源与账号体验**：
  - 实现 QQ / 微信双渠道登录凭证自动续期与过期透明重试。
  - 修复酷狗收藏下载、20028 自愈与高音质参数，修复网易云红心同步、B 站日志与 Navidrome 封面缓存/下载格式及交互问题。
  - 修复迷你窗状态竞态、队列重复曲死循环及多项前后端性能与稳定性问题。
