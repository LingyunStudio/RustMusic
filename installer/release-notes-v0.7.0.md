# RustMusic v0.7.0

## 新功能

- **全新极简独立小窗模式（Mini Player）**：
  - 彻底摆脱传统主窗口内嵌条形态，一键转变为轻巧独立的桌面悬浮小窗（360×118px），主界面边栏、标题栏与内容区完全隐藏，极致精简与轻量。
  - 内置实时对位歌词条（MiniLyricBar），毫秒级逐行滚动，长歌词平滑跑马灯，支持中文译文同步展示与纯音乐优雅降级。
  - 支持整窗自由拖拽（`data-tauri-drag-region`），支持一键窗口全置顶（Pin）、最小化与关闭。
  - 支持多区域双击（封面/曲目信息/歌词栏/空白区）与右上角一键还原主窗口，Rust 原生底层命令与前端窗口调度双重保障，精准恢复原窗口分辨率与位置。
- **全平台顶级音质体系（SVIP/VIP）与无损下载**：
  - **QQ 音乐**：支持标准(128k)、HQ(320k)、SQ无损(FLAC)、Hi-Res(24bit)，以及 SVIP 专属的「臻品音质2.0」、「臻品全景声」与「臻品母带(192kHz)」。
  - **网易云音乐**：支持标准(128k)、极高(320k)、无损(FLAC)、Hi-Res(24bit)，以及 VIP/SVIP 专属的「高清环绕声」、「沉浸环绕声」与「超清母带」。
  - **酷狗音乐**：支持标准(128k)、HQ(320k)、SQ无损(FLAC)、Hi-Res(24bit)，以及 SVIP 专属的「蝰蛇超清」、「蝰蛇全景声」与「蝰蛇母带」。
  - 设置页支持三源音质独立选档，播放、缓存与下载均严格按所选音质生效，具备自动阶梯降级与去重提示。
- **酷狗音乐官方移动端双通道兜底**：
  - 酷狗音频取链增加官方移动端网关自动双通道兜底，彻底解决旧接口在未登录状态下频控报错（`1002`）导致播放失败的问题。

## 优化

- **全界面滚动条隐形化**：彻底移除全软件、全主题（标准/拟物/液态玻璃）所有位置的系统滚动条，保持完整鼠标滚轮与手势平滑滚动能力。
- **拟物风格（Skeuomorphic）深度视觉优化**：
  - 移除粗糙扫描线背景纹理，升级为细腻的冷轧金属拉丝机架面板与沉头金属车削螺栓质感。
  - 修复标题栏横线切过侧边栏 Logo 铭牌的排版冲突，恢复干净利落的物理金属铭牌。
  - 优化曲库页与歌单页操作栏，重构排版为双行自适应布局，搜索框与播放操作按钮互不遮挡。
- **音频引擎混音与均衡器优化**：多声道（5.1/7.1）向下混音算法优化，修复浮点常数精度损耗。

## 修复

- 修复了极端情况下点击小窗还原主窗口因 Windows 窗口尺寸约束顺序冲突导致的尺寸死锁问题。
- 修复了小窗进度条在拖动时被外部系统窗口打断时指针捕获可能残留的问题。
