# RustMusic v0.5.0

## 新功能：在线音源边下边播

点播一首未缓存的在线歌曲（网易云 / QQ / 酷狗 / B站）不再需要等整段下载完成：预缓冲约 512KB 即刻起播，后台继续下载，拖动进度到未下载区域会短暂等待数据后继续。听过的歌仍完整进缓存，二刷秒开。无总长度（chunked 响应）等特殊场景自动回退旧的整段下载模式。

- WASAPI 独占模式对边下边播曲目同样生效（协商失败自动回退共享模式）

## 在线音质体系治理（网易云 / QQ / 酷狗）

此前设置选择 HQ / 无损后，实际下发音质受账号权益影响时会**无声无息地降级**，播放栏标签也按设置档位而非真实档位显示。本版本修复：

- **网易云**：升级到 v1 按档位取流接口——账号有无损权益时真实下发 FLAC（旧接口的码率阶梯拿不到无损档），逐级回退 standard
- **QQ 音乐**：播放栏音质标签改为实际下发的档位（无损/HQ/标准）
- **酷狗**：匿名通道实测仅提供标准音质，HQ/无损需扫码登录按会员权益取链；从最近播放 / 收藏 / 歌单下载或播放时，自动按"标题+歌手"反查补齐各档质量 hash（此前只有 128k hash，音质设置静默失效）；下载请求透传搜索结果自带的各档 hash
- **三源统一**：设置档位未达成时明确提示实际音质与原因，不再静默降级

## 修复：酷狗榜单与时长

- **榜单只显示 30 首**：酷狗榜单接口此前写死单页 30 条且不翻页（TOP500 只能拿到零头），现改为按页加载——榜单页点开秒进（首屏 90/100 首），列表底部"加载更多"逐页追加；网易云、QQ 榜单同样分页
- **榜单歌曲时长千倍错误**：榜单接口的时长字段本就是毫秒，被误判为秒再次乘 1000 入库（3:18 的歌显示成 55 小时），列表时长与进度条拖动全部异常；已修正换算并自动修复历史数据

## 修复：点击进度条概率性切歌

seek 目标越过曲目末尾时，播放位置曾回退为无效的估算值（幻影位置），引擎随即误判"自然播完"而自动切下一首。现回退到最后一个音频包的真实位置，行为与"seek 到末尾即收尾切歌"的惯例一致。
