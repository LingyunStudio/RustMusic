# RustMusic v0.7.1

## v0.7.1 修复与细节优化

- **迷你模式长歌词平滑跑马灯滚动**：
  - 彻底修复极简独立小窗模式（Mini Player）在歌词文本过长时无法滚动显示的问题。
  - 引入离屏标尺毫秒级精准测宽机制，对比实际容器宽度自动触发平滑跑马灯动效；切歌或歌词行切换时无缝重启滚动，保证超长歌词完整可读。
- **资料库与「我喜欢」工具栏单行自适应排版**：
  - 彻底解决在默认窗口尺寸以及系统高 DPI 缩放下，资料库、「我喜欢」及最近播放页面的搜索框被挤压换行、无法与前排控制按钮处于同一行的排版问题。
  - 重构工具栏布局为单行弹性流（`flex-nowrap`），优化「播放全部」「随机」「批量管理」与各排序标签的尺寸间距，搜索框靠右弹性收缩自适应，确保任意窗口比例下均整齐同行展示。
- **歌曲列表格式标签与列宽对齐优化**：
  - 彻底修复歌曲列表中「在线」标识以及无损音质（如「FLAC」）标签在特定列宽下出现的汉字竖向折行异常（「在」与「线」上下分行）。
  - 拓展格式与时长列宽度（80px → 104px），增加绝对禁止文本折行（`whitespace-nowrap`）约束与紧凑边距规范。
  - 标准、复古拟物、液态玻璃三大设计体系与资料库、歌手专辑、歌单详情等所有列表网格列宽全面对齐统一。

# RustMusic v0.7.0 全部更新内容

## 新功能

- **三大界面设计体系上线（标准 / 液态玻璃 / 复古拟物）**：
  - **全新「液态玻璃（Liquid Glass）」主题**：轻盈通透的毛玻璃材质、统一规范的卡片圆角体系、左右两列面板垂直对齐、强调色派生渐变，带来现代通透的视觉体验。
  - **全新「复古拟物（Skeuomorphic）」主题**：细腻质感的冷轧金属拉丝机架面板、沉头金属螺栓、立体微浮雕旋钮、拟物化播放控制台与独立金属 Logo 铭牌，还原经典发烧级 Hi-Fi 硬件质感。
  - 支持在设置中自由切换三大界面风格，各主题均经过深度打磨与高分辨率适配。
- **全新极简独立小窗模式（Mini Player）与实时同步歌词**：
  - 支持一键将播放器切换为独立的轻量桌面悬浮小窗（360×118px），主界面边栏与多余内容完全隐藏，纯粹沉浸听歌。
  - 内置实时对位歌词条（MiniLyricBar），毫秒级逐行滚动与长歌词平滑跑马灯，支持中文译文同步对照与纯音乐优雅降级。
  - 支持整窗自由拖拽移动（`data-tauri-drag-region`）、一键窗口置顶（Pin）、最小化与托盘联动。
  - 支持小窗内多区域双击（封面/曲目信息/歌词条/空白区域）或点击右上角按钮即刻精准还原主窗口。
- **系统级凭据安全管理与更新验签**：
  - 四大音源平台（QQ、网易云、酷狗、B站）登录凭据由原本地配置明文存储全面迁移至系统级凭据管理器（Windows Credential Manager / 系统 Keyring），应用启动自动无感迁移并清空明文。
  - 应用内置 Ed25519 签名校验机制，自动更新安装包（`.sig`）下载后必须验签通过才允许安装，防止劫持与篡改。
  - 酷狗与 QQ 多处网络接口及流媒体地址全面迁移至 HTTPS 加密链路；进一步收紧 Tauri CSP 策略与静态资源访问作用域。

## 音质与取链优化

- **三源播放音质独立设置与官方规范对齐**：
  - 网易云、QQ 音乐、酷狗音乐支持独立设置播放音质档位，档位选项按各官方 App 规范命名对齐（标准 128k / HQ·极高 320k / SQ 无损 FLAC / Hi-Res 24bit）。
- **QQ 音乐 Hi-Res 取链接入与探测降级**：
  - 接入单曲详情接口获取真实的 `media_mid`，解决旧版因文件名只能猜测导致 Hi-Res 取到无效 `purl` 的问题。
  - 增加 RS01 真实 purl 下载探测，探测失败时自动平滑回落至无损 FLAC 并给予提示，杜绝播放 404 报错。
- **网易云与酷狗取链容错增强**：
  - 网易云音质取链重构阶梯容错，非 200 响应不再中断整条取链，而是按可用档位逐级平滑回退。
  - 酷狗音频取链增加官方移动端网关自动双通道兜底，解决旧接口在免登录状态下因频控（`1002`）导致播放失败的问题。

## 修复与体验改进

- **音频解码与本地曲库**：
  - 修复 WAV 音频文件因缺少 PCM 解码器导致无法解码播放的问题（启用 `symphonia-pcm`）。
  - 本地曲库标签解析采用宽松容错模式，避免因不规范 ID3 字段导致解析失败，历史扫描出的 0 时长曲目在下次扫描时自动自愈。
  - 本地曲库实现引擎底层无缝预载切歌。
- **任务栏歌词低内存休眠优化**：
  - 任务栏歌词推进改由 Rust 底层 monitor 线程独立定时调度，彻底解决前台 WebView2 最小化进入低内存挂起休眠时任务栏歌词冻结停摆的问题。
- **界面交互优化**：
  - 彻底移除全软件、全主题（标准/拟物/液态玻璃）所有位置的原生系统滚动条，保持完整平滑的鼠标滚轮与触控板手势滚动。
  - 歌曲列表支持键盘快捷键批量选择（<kbd>Ctrl+A</kbd> 全选 / <kbd>Ctrl+D</kbd> 清空选择）。
  - 修复拟物主题下标题栏分割线横切侧边栏 Logo 铭牌的视觉重叠瑕疵。
  - 重构曲库页与歌单页头部操作栏排版为双行自适应布局，消除搜索框与操作按钮之间的挤压遮挡。
